# Стихии: Доктрина Хаоса — идеи взаимодействий (Design Ideas)

> **📌 Статус:** 💡 Идеи/дизайн (v0). Не реализация — концепция «всего со всем». ГДД зафиксировал базовые пары (§GameConfig.combinations); здесь — расширение до полной решётки и каскадов.
> **🎯 Принцип:** на экране творится дичь и ад. Монстры — топливо, стихии — инструменты, статусы — связующее звено. Всё взаимодействует со всем, цепочки усиливают друг друга.

---

## ⚛️ 1. Алфавит: базовые стихии и катализаторы

| Стихия | Роль | Статус, который вешает |
|--------|------|------------------------|
| 🔥 Огонь | Урон, распространение | **Горение** (tint оранжевый, пульсация) |
| 💧 Вода | Гашение, смыв, охлаждение | **Мокрый** (tint синий) |
| 🌍 Земля | Барьеры, удержание | **Грязный** (tint коричневый, замедление) |
| 💨 Воздух | Разброс, подброс | **Парящий** (tint белый, подброшен) |
| ⚡ Молния (сила бога) | Катализатор: усиливает всё, цепные разряды | **Заряжен** (tint жёлтый, искрит) |

Правило алфавита: **любая пара базовых → новый продукт; любой продукт + любая стихия → каскад**. Продукты можно комбинировать между собой.

## 🃏 2. Решётка пар (бинарные комбинации)

| | 🔥 Огонь | 💧 Вода | 🌍 Земля | 💨 Воздух |
|---|---|---|---|---|
| **🔥 Огонь** | — | **Пар** (§3) | **Лава** (§3) | **Огненный смерч** (§3) |
| **💧 Вода** | Пар | — | **Грязь** (§3) | **Ледяная буря** (§3) |
| **🌍 Земля** | Лава | Грязь | — | **Пылевая буря** (§3) |
| **💨 Воздух** | Огненный смерч | Ледяная буря | Пылевая буря | — |

### Продукты первого уровня

**🔥+💧 = Пар** — поднимается вверх, «парит» монстров: они отрываются от земли (статус **Парящий**), не могут атаковать землю и барьеры, падают с уроном. Горячий пар слепит — монстры **Ослеплены**, блуждают.
*ГДД: `fire_water → steam (area_damage)` — усиливаем механикой подброса.*

**🔥+🌍 = Лава** — течёт вниз по склону/полю, **уничтожает монстров на пути** (игнорируя HP — расплавление), поджигает землю-барьер (если течёт по ней). Через N секунд **застывает** в обсидиановую корку (крепкий барьер), ещё через N — рассыпается и исчезает. По застывшей лаве можно рисовать поверх.

**🔥+💨 = Огненный смерч** — живёт и движется (к базе монстров/в сторону плотности), **засасывает** монстров внутрь (статус **Парящий** + **Горение** одновременно), на выходе — расшвыривает дымящихся.
*ГДД: `fire_air → fire_tornado (push)` — добавляем движение и засасывание.*

**💧+🌍 = Грязь** — пятно/поток, **замедляет** всё, что по ней идёт (статус **Грязный**). Грязные монстры **проводят электричество**: цепная молния бьёт по ним всех сразу. Со временем грязь высыхает в корку земли.
*ГДД: `water_earth → mud (slow)` — проводимость — новая связка с молнией.*

**💧+💨 = Ледяная буря** — локальная вьюга, **замораживает** монстров (статус **Заморожен**: полный стоп). Замороженные получают **дополнительный урон при любом ударе** (молния, толчок, столкновение) и могут разлетаться на осколки (осколки режут соседей).

**🌍+💨 = Пылевая буря** — накрывает зону, медленный урон и **Ослепление** (блуждают), мелкие монстры **Засыпаны** (почти стоят). Пыль проводит молнию и хранит заряд: молния внутри бури превращается в «пылевую молнию» — бьёт каждые 0.5 с по всем в зоне.

## ⚡ 3. Катализатор: Молния + продукт/стихия

| Комбо | Результат |
|-------|-----------|
| ⚡ + 💨 Пар | **Грозовое облако** — парит над зоной, **парализует** монстров (статус **Паралич**: стоят, искрят), **запускает цепные молнии** по парализованным каждые ~2 с |
| ⚡ + ☁️ Грозовое облако + 💨 Воздух | **Шторм** — всё поле боя начинает жить: монстров **расшвыривает в разные стороны**, при столкновении друг с другом/препятствиями они **уничтожаются** (столкновения = урон) |
| ⚡ + 💧 Вода/Мокрые | **Электроразряд** — каждый мокрый монстр — проводник: молния прыгает по всей «мокрой сети» (все, кого коснулась вода за последние секунды) |
| ⚡ + 🌍 Земля-барьер | **Заряженная земля** — барьер искрит: касающиеся монстры горят и парализуются; в землю можно «закачать» несколько зарядов |
| ⚡ + 🔥 Огонь | **Плазменная дуга** — жгущая дуга между ближайшими монстрами, цепное горение с уроном дугой |
| ⚡ + 💨 Воздух | **Гроза** — молнии бьют случайно по полю N секунд, каждая попадание — разряд + шанс поджечь/заморозить (случайная стихия) |
| ⚡ + 🟤 Грязь | **Электро-грязь** — все **Грязные** получают разряд одновременно (шок-волна по грязи) |

## 🔗 4. Каскады и дичь (3+ элементов)

| Каскад | Что происходит |
|--------|----------------|
| 🔥+💧+💨 | **Паровой взрыв** — Пар + воздух: всё в зоне расшвыривается, ожоги, вторичный пар по всему полю |
| 🌋 Лава + 💧 Вода | **Обсидиан** — лава застывает мгновенно: супер-барьер, но хрупкий к молниям (раскалывается разрядом) |
| 🟤 Грязь + 🔥 Огонь | **Керамика** — обожжённая грязь затвердевает в барьер; **жаростойкий** (огонь поверх неё не течёт) |
| 🟤 Грязь + 💨 Воздух | **Грязевой поток** — вздувается и течёт вниз, смывая толпу к базе/в сторону; грязные монстры скользят |
| ❄ Лёд + 🔥 Огонь | Пар обратно — **замыкание цикла**: паровой взрыв вокруг разморозки |
| 🌪 Огненный смерч + 💧 Вода | **Паровой смерч** — скрывает зону (монстры Ослеплены), горячий пар жжёт |
| 🌪 Пылевая буря + 💧 Вода | **Сель** — грязевой поток с быстрым смывом + замедление |
| ⛈ Грозовое облако + 🌋 Лава | **Молниевый обсидиан** — лава заряжается: застывший барьер бьёт разрядами касающихся |
| 🌪 Шторм + 🌋 Лава | **Огненный шторм** — финальный ад: лавовые фонтаны, молнии, расшвыривание, всё горит |
| 🌪 Шторм + ❄ Лёд | **Ледяной шторм** — расшвыривает + замораживает в полёте: монстры падают осколками |
| ВСЁ СРАЗУ | **Концерт** (финальный синтез) — редкий/дорогой финал: экранная вспышка, всё поле выжигается, остаётся обсидиановая корка + дым |

## 🧟 5. Статусы монстров (связующее звено всей системы)

| Статус | Визуал (tint/эффект) | Механика |
|--------|----------------------|----------|
| Горение 🔥 | Оранжевый, пульсация | Урон в секунду; **цепное горение**: горящий передаёт огонь ближайшим (толпа = топливо) |
| Мокрый 💧 | Синий, капли | Проводит молнию; скользит (хуже тормозит); гасит огонь |
| Грязный 🟤 | Коричневый | Замедлен; проводит разряд по грязи |
| Заморожен ❄ | Голубой/белый | Полный стоп; +урон от ударов; разлетается осколками |
| Паралич ⚡ | Жёлтый, искры | Стоп + периодический разряд соседям |
| Парящий ☁️ | Белый, тень | Не атакует землю/барьеры; падает с уроном |
| Ослеплён 👁🗨 | Серый | Блуждает случайно |
| Засыпан 🏜 | Земляной | Почти стоит, медленный урон |
| Заряжен ⚡ | Жёлтый | Передаёт разряд контактом (цепь) |

Правило: **статусы складываются** (горящий + мокрый = пар локально), **молния усиливает всё** — она «решает», какой статус станет катализатором.

## 🌪 6. Массовые синергии («ад» как механика)

- **Толпа = топливо:** огонь распространяется по монстрам, чем плотнее толпа — тем быстрее горит (эффект масштаба автоматический, per-monster не нужен).
- **Цепные каскады:** одно попадание молнии в грязную толпу → электро-грязь → зарядка → гроза → шторм. Игрок строит цепочки, а не одиночные атаки.
- **Лава как река:** рисование лавы по направлению склона — «рисование потока», который живёт, течёт и умирает (застывает).
- **Столкновения = урон** (шторм, паровой взрыв): толпа сама себя убивает при расшвыривании — визуальный хаос без расчёта урона на каждую пару.
- **Зоны-«инструменты»:** грозовое облако висит и работает само (заряды, цепные молнии) — игрок рисует следующий слой хаоса поверх.

## ⚖️ 8. Принципы дизайна (не правила, а дух)

1. **Любое сочетание = что-то весёлое.** Нет «пустых» пар. Если пара не придумана — дать случайный «крит стихий».
2. **Каскады растут:** 2 элемента → зона, 3 → движущийся хаос, 4+ → весь экран. Стоимость/мана растёт так же.
3. **Монстры — материал:** статусы складываются, толпа усиливает эффекты — игроку выгодно нарисовать хаос, а не зачищать точечно.
4. **Всё исчезает:** лава застывает, грязь высыхает, облака рассеиваются — поле не «залипает», хаос всегда свежий.
5. **Хаос управляемый:** направление лавы/смерча/потока определяется жестом рисования — игрок дирижирует, а не наблюдает.

## 🔧 9. Технические заметки (мост к реализации)

- Все эффекты строятся на **статусах монстров** (tint + пульсация, §PERFORMANCE.md 3.7) — тысячи затронутых монстров не ломают FPS.
- Зоны/живые объекты (пар, смерч, облако, лава) — через **EffectManager** (пул спрайтов + атлас эффектов, §PERFORMANCE.md §5) с жёстким бюджетом и приоритетами.
- Столкновения-урон (шторм) — агрегированно (зонная проверка), не попарно.
- Грозовое облако/смерч/шторм — «живые объекты» с простым поведением (движение к плотности, тикер разрядов), без сложного ИИ.
- Референсы реализации базовых пар: `GameConfig.combinations` (`fire_water`, `water_earth`, `fire_air`) в `src/game/config/GameConfig.ts`; док текущей системы — `ELEMENT_SYSTEM.md`.
