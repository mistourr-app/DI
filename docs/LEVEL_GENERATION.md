# Level Generation Design Document

> **📌 Статус:** В разработке  
> **🏷️ Ветка:** `phase2/level-generation`  
> **🎯 Цель:** Реализовать детерминированную генерацию уровней по seed для игры Fluid Crowd Defense

---

## 📚 1. Терминология

### Области экрана
| Область | Описание | Пропорция |
|---------|----------|-----------|
| **Игровое поле** | Общая область игры (соотношение 9:19.5) | 100% |
| **Поле боя** | Область для лабиринта и монстров | 5/6 высоты игрового поля |
| **Зона базы** | Нижняя область с базой и элементами | 1/6 высоты игрового поля |

### Компоненты уровня
| Компонент | Расположение | Назначение |
|-----------|-------------|------------|
| **Входы (Spawn Points)** | Верхняя граница поля боя | Точки появления монстров |
| **Выходы (Passages)** | Нижняя граница поля боя | Проходы к базе |
| **Лабиринт** | Внутри поля боя | Набор препятствий для монстров |
| **Препятствия (Obstacles)** | Внутри поля боя | Стены, замедляющие/блокирующие монстров |

### Логика движения
- Монстры появляются **на входах** (верх поля боя)
- Двигаются **сверху вниз** к базе
- Проходят через **выходы** в зону базы
- При столкновении с препятствиями: **обходят или останавливаются**

## 🎯 3. Технические требования

### Детерминированность
- ✅ Один и тот же `seed` должен генерировать **идентичный уровень**
- ✅ Уровень должен адаптироваться под **размеры экрана** (9:19.5)
- ✅ Генерация должна быть **быстрой** (не блокировать UI)

### Интеграция
- ✅ Генератор должен работать с `GameScene`
- ✅ Уровень должен перегенерироваться при **изменении размеров экрана**
- ✅ `seed` должен сохраняться/загружаться через `SaveSystem`

### Физика
- ✅ Препятствия должны быть **непроходимыми** для монстров
- ✅ Монстры должны **обходить** или **останавливаться** у препятствий

## 🔧 6. Технические детали

### Алгоритм генерации
1. **Генерация входов (Spawn Points)**
   - Распределяются равномерно по верхней границе поля боя
   - Количество: `spawnPointsCount` (по умолчанию: 5)
   - Координаты: `(x, battlefieldZone.y)`

2. **Генерация выходов (Passages)**
   - Распределяются равномерно по нижней границе поля боя
   - Количество: `passagesCount` (по умолчанию: 3)
   - Координаты: `(x, battlefieldZone.y + battlefieldZone.height)`

3. **Генерация препятствий (Obstacles)**
   - Используется **Simplex Noise** для естественного распределения
   - Препятствия генерируются **внутри поля боя**, отступив от границ
   - Минимальное расстояние от границ: `minMargin` (по умолчанию: 50px)
   - Плотность: `obstacleDensity` (0.0 - 1.0)

4. **Гарантия проходимости**
   - Между входами и выходами создаются "коридоры"
   - Минимальная ширина коридора: `minPassageWidth` (по умолчанию: 60px)

### Пример кода (псевдокод)
```typescript
// Генерация уровня
const level = levelGenerator.generate({
  seed: 'my-seed-123',
  width: battlefieldZone.width,
  height: battlefieldZone.height,
  spawnPointsCount: 5,
  passagesCount: 3,
  obstacleDensity: 0.4,
  minPassageWidth: 60,
  minMargin: 50
});

// Использование в GameScene
level.spawnPoints.forEach(spawn => {
  this.createEnemyAt(spawn.x, spawn.y);
});

level.obstacles.forEach(obstacle => {
  this.createObstacle(obstacle);
});
```

## ✅ 7. Критерии приемки

### MVP (Фаза 1)
- [ ] Уровень генерируется по seed
- [ ] Входы и выходы расположены на границах поля боя
- [ ] Препятствия отображаются на экране
- [ ] Монстры не проходят сквозь препятствия
- [ ] Уровень адаптируется под размеры экрана

### Полная реализация
- [ ] Монстры обходят препятствия
- [ ] От каждого входа есть путь к выходу
- [ ] Seed сохраняется и загружается
- [ ] Визуализация входов/выходов в debug-режиме
- [ ] Настраиваемые параметры генерации
