# Game Design Document: Fluid Crowd Defense

## 1. Обзор игры

**Название:** Fluid Crowd Defense  
**Жанр:** Стратегия с видом сверху  
**Платформа:** PWA (Progressive Web App)  
**Целевая аудитория:** Игроки, интересующиеся стратегиями и физическими симуляциями

**Краткое описание:**  
Игра, в которой игрок защищает базу от орд врагов (до 1000 на экране), используя систему комбинируемых стихий. Враги ведут себя как жидкость - плавно обтекают препятствия.

## 2. Основные механики

### 2.1 Поведение врагов (Fluid Simulation)
- **Количество:** До 1000 врагов на экране
- **Поведение:** Моделирование жидкости
- **Визуализация:** Маленькие спрайты, объединенные в "поток"

### 2.2 Система стихий
- **Базовые элементы:** Огонь, Вода, Земля, Воздух
- **Взаимодействие:** Комбинации элементов (Огонь+Вода=Пар и т.д.)
- **Применение:** Тап + слайд пальцем по экрану
- **Стоимость:** Трата ресурсов (маны)

### 2.3 Структура экрана
- **Поле боя:** 5/6 высоты экрана
- **Зона базы:** 1/6 высоты экрана
- **Ориентация:** Портретная (вертикальная)
- **Адаптивность:** Под все размеры экранов

## 3. Технический стек

### Основной стек:
- **Игровой движок:** Phaser.js 3.55+ (WebGL)
- **Язык:** TypeScript 5.0+
- **Сборщик:** Vite 5.0+ с PWA плагином
- **Архитектура:** ECS (bitecs + miniplex)

### Для производительности:
- **Web Workers** для fluid simulation
- **Object Pooling** для переиспользования объектов
- **Texture Atlas** для спрайтов
- **Batch Rendering** в Phaser

### Для PWA:
- **Service Workers** для офлайн-работы
- **Web App Manifest** для установки
- **IndexedDB** для сохранения прогресса

## 6. Архитектура проекта

### Структура папок:
```
src/
├── game/              # Игровая логика
│   ├── ecs/          # ECS система
│   ├── generation/   # Генерация уровней
│   ├── save/         # Система сохранения
│   └── utils/        # Вспомогательные функции
├── scenes/           # Сцены Phaser
└── assets/           # Ресурсы
```

### Ключевые системы:
1. **CrowdFluidSystem** - симуляция поведения толпы
2. **ElementSystem** - обработка стихий и комбинаций
3. **LevelGenerator** - процедурная генерация уровней
4. **SaveSystem** - автосохранение и загрузка
