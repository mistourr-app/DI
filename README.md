# Fluid Crowd Defense

![Game Banner](docs/banner.png)

**Стратегическая PWA игра с fluid simulation толпы и системой комбинируемых стихий**

## 🎮 О проекте

Fluid Crowd Defense - это инновационная стратегическая игра, в которой вы защищаете базу от орд врагов (до 1000 на экране), используя систему комбинируемых стихий. Враги ведут себя как жидкость - плавно обтекают препятствия, создают "заторы" и ищут новые пути.

### Ключевые особенности:
- **🔄 Fluid Crowd Simulation:** Реалистичное поведение толпы как жидкости
- **⚡ Element Combination System:** Огонь+Вода=Пар, Земля+Вода=Грязь и другие комбинации
- **🎲 Procedural Generation:** Уровни генерируются по seed'ам
- **📱 PWA:** Установка на домашний экран, офлайн-работа
- **👆 Touch Controls:** Управление жестами на мобильных

## 🚀 Быстрый старт

### Предварительные требования
- Node.js 18+ 
- npm или yarn
- Современный браузер с поддержкой WebGL

### Установка
```bash
# Клонировать репозиторий
git clone [repository-url]
cd fluid-crowd-defense

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev

# Собрать для production
npm run build

# Просмотреть production сборку
npm run preview
```

## 🛠 Технологический стек

### Основной стек:
- **Phaser.js 3.60+** - игровой движок с WebGL рендерингом
- **TypeScript 5.0+** - типизированный JavaScript
- **Vite 5.0+** - быстрый сборщик с PWA плагином
- **ECS Architecture** - bitecs + miniplex для масштабируемости

### Оптимизации:
- **Web Workers** - вынос физики в отдельный поток
- **Object Pooling** - переиспользование объектов
- **Texture Atlas** - объединение спрайтов
- **Spatial Partitioning** - оптимизация коллизий

## 📋 План разработки

### Фаза 1: Базовый каркас (2 недели) - ТЕКУЩАЯ
1. Настройка проекта (Vite + Phaser + TypeScript)
2. Адаптивная верстка (поле боя + зона базы)
3. Базовое движение врагов (100 врагов)
4. Простая система сохранения

### Фаза 2: Core геймплей (3 недели)
1. Fluid simulation через Web Workers
2. Система стихий (4 элемента + комбинации)
3. Рисование стихий пальцем
4. Генерация уровней по seed'ам

### Фаза 3: Полировка (3 недели)
1. Увеличение до 1000 врагов + оптимизации
2. PWA настройки (офлайн, иконки)
3. Тестирование на мобильных устройствах
4. Балансировка и фиксы

**Всего: 8 недель разработки**
